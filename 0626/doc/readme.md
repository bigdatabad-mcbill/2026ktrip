
# 🗺️ CloseTrip(클로즈트립) 서비스 UX·기술·사업·론칭 통합 설계안

본 문서는 외국인도 즉시 이해할 수 있는 **다국어·다문화 UX를 중심 구조**로 하며, 실제 개발 가능한 수준을 목표로 작성된 **CloseTrip**의 통합 설계안입니다. MVP(최소 기능 제품)에서 검증 가능한 범위와 향후 고도화 범위를 분리하여 제안합니다.

---

## 1. 서비스 개요 및 핵심 가치

**CloseTrip**은 “오늘 어디 가고, 무엇을 입고, 어디서 찍고, 어떻게 남길지”를 단 하나의 흐름으로 연결하는 컨텍스트 기반 여행 앱입니다.

* **서비스 한 줄 정의:** 여행자의 현재 위치·일정·날씨·장소 특성을 결합해 **즉시 행동 가능한 여행 의사결정**을 돕는 다국어 가이드.
* **핵심 UX 원칙:**
    1. **즉시성 (Immediacy):** 앱 실행 후 3분 이내에 오늘의 여행 플랜 확정.
    2. **신뢰성 (Explainability):** "Why this?" UI를 통해 모든 추천의 명확한 근거(기온, 바람, TPO 등) 제공.
    3. **현지성 (Localization):** 단순 번역을 넘어 단위(°C/°F, km/mi), 시간(12/24h), 문화적 톤앤매너까지 최적화.
    4. **기록 자동화 (Automation):** 사진 메타데이터(EXIF)와 위치 로그 기반의 자동 다이어리 생성.

## 2. 타깃 사용자 및 페르소나

### 👥 타깃 고객 분류
* **1차 타깃:**
    * **국내 여행자 (20~39세):** 주말 나들이, 인스타그래머블(Instagrammable) 카페/전시 투어, 사진 중심 여행자.
    * **방한 외국인 관광객:** 서울·부산·제주 등 도시를 여행하며 언어·지리·문화적 장벽을 느끼는 여행자.
* **2차 타깃:** 여행 콘텐츠 제작자(크리에이터), 패션 고관여 유저, 가벼운 자동 기록 선호자.

### 👤 페르소나 예시
* **국내 유저 A (28세, 직장인):** 주말 성수동 카페 투어 예정. 날씨 급변에 따른 코디(아우터 필요 여부)와 실패 없는 인생샷 스폿을 빠르게 찾고 싶어 함.
* **외국인 유저 B (24세, 미국인 대학생):** 첫 한국 방문. 한국어를 전혀 못 함. 앱 진입 즉시 영어 설정이 필요하며, 현재 위치 기반의 인기 스폿과 촬영 구도 가이드가 필수적임.

## 3. 핵심 사용자 시나리오 (User Journey)


```

[앱 실행 및 다국어 온보딩] ➡️ [홈: 오늘의 날씨 & 코디 확인] ➡️ [스폿: 지도 기반 촬영지 이동] ➡️ [카메라: AR 구도 가이드 촬영] ➡️ [다이어리: 자동 생성 기록 확인]

```

1.  **진입 & 온보딩:** 첫 실행 시 언어/단위를 즉시 선택하고, 가벼운 스타일 취향(카페, 산책, 전시 등)을 입력합니다.
2.  ** 탐색 & 준비:** 홈 화면에서 오늘 날씨에 딱 맞는 옷차림(예: "기온 18°C, 가벼운 코트+운동화")을 확인하고 출발합니다.
3.  **현장 경험:** 지도(Spot)에서 목적지 주변의 포토스폿과 혼잡도를 확인한 후, 카메라(Camera) 가이드를 켜고 완벽한 구도로 사진을 찍습니다.
4.  **기록 아카이빙:** 저녁이 되면 앱이 장소 로그와 사진을 결합해 자동으로 다이어리 초안을 완성해 줍니다.

## 4. 정보 구조 (IA) 및 화면별 UX 상세

### 📱 정보 구조 (Information Architecture)
하단 네비게이션은 인지 부하를 줄이기 위해 **5개 탭 구조**를 권장하며, 카메라는 Spot/Diary 내 플로팅 버튼 또는 중앙 액션 버튼으로 배치합니다.
* **Home** (오늘의 요약) | **Trip** (일정 및 경로) | **Spot** (지도·포토스폿) | **Diary** (자동 기록) | **My** (설정 및 단위)

---

### 4-1. 화면별 핵심 UX 설계

#### ① 온보딩 (Onboarding)
* **원칙:** 선(先) 가치 경험, 후(後) 권한 요청. 시스템 권한(위치·사진)은 기능 진입 시점에 필요성을 명시하며 요청함.
* **다국어 카피 예시:**
    * *KO:* "오늘의 여행 스타일을 골라주세요." / *EN:* "Pick your travel style."

#### ② 홈 화면 (Home)
* **역할:** 오늘의 핵심 의사결정 허브.
* **UI 구성 요소:** Today Trip Summary 카드, 날씨 변화 그래프, 추천 코디(상/하의 및 아우터 제안), 주변 인기 스폿 Top 3.
* **빈 상태(Empty State) 대응:** 일정이 없을 때 *"일정을 추가하면 더 정확한 코디를 추천받을 수 있어요"* 문구 노출.

#### ③ 일정 (Trip) 화면
* **역할:** 수동 입력 및 캘린더 연동을 통한 날짜별 카드형 타임라인 제공. 각 여정마다 예상 체류 시간 및 이동 경로(Route)를 날씨 피드백과 함께 표시.

#### ④ 코디 추천 (Style) 화면
* **Explainable UI ("Why this?"):** 단순 스타일 제안이 아닌 추천 근거 명시.
    * *예시:* "낮과 밤의 기온 차가 10°C 이상 벌어집니다. 입고 벗기 편한 얇은 겉옷을 추천합니다."
    * *데이터 연동:* 기온, 강수확률, 바람세기, 도보 이동량 정보 결합.

#### ⑤ 포토스폿 (Spot) 화면
* **구조:** 지도(Map) 뷰와 리스트(List) 뷰 스위칭.
* **글로벌 최적화:** 유저 Locale에 따라 거리 단위(`km`, `m` ↔ `mi`, `ft`) 자동 전환. 필터(실내외, 야경, 비 오는 날, 외국인 인기) 제공.
* **카피 예시:** *EN:* "Best at sunset." (해질 무렵 가장 예쁜 곳)

#### ⑥ 카메라 (Camera) 화면
* **구조:** 촬영 화면 위 반투명 AR 구도 오버레이(Overlay) 제공. "인물은 왼쪽 1/3 선에 맞추세요", "수평을 맞춰보세요" 등 직관적인 그래픽 가이드 적용. 촬영 즉시 위치·시간 태그 자동 매핑.

#### ⑦ 다이어리 (Diary) 화면
* **자동 생성 엔진:** EXIF 데이터와 GPS 로그를 바탕으로 스토리 텍스트 자동 빌드.
    * *생성문 예시:* "오전에는 비가 왔지만 오후부터 맑아져 성수동 카페와 전시를 즐겼습니다."
* **내보내기:** SNS(인스타그램 스토어 등) 최적화 템플릿 및 PDF 저장 기능.

#### ⑧ 설정 (Settings) 화면
* 첫 온보딩의 설정을 언제든 바꿀 수 있는 창구. 언어(7개국어), 온도 단위(°C/°F), 거리 단위, 사진/위치 권한 철회, 오프라인 모드 데이터 관리 기능 포함.

## 5. 다국어 / 현지화(Localization) 및 문화 대응 정책

* **지원 언어 우선순위:** 한국어 ➡️ 영어 ➡️ 일본어 ➡️ 중국어(간체/번체) ➡️ 태국어 ➡️ 베트남어
* **레이아웃 유연성:** 영문·유럽어권 단어의 길이 확장(Text Overflow)을 고려해 버튼과 텍스트 박스는 자동 줄바꿈 및 유동형(Auto-layout)으로 설계.
* **UI 톤앤매너 최적화:**
    * **영어:** 직관적이고 명확한 행동 중심 (Action-oriented) 표현 (*Example: "Best to visit now"*)
    * **일본어:** 정중하고 맥락을 배려하는 표현
    * **한국어:** 친근하고 유행에 민감한 무드 중심 표현
* **포용적 디자인(Inclusive Design):** 이미지 소스 사용 시 특정 성별·연령·인종에 대한 고정관념을 배제하고, 글로벌 보편적인 장소성을 유지.

## 6. 기술 아키텍처 및 추천 엔진 구성

### 🏗️ 시스템 아키텍처 다이어그램


### 🛠️ 기술 스택 (Tech Stack)
* **Frontend:** Cross-platform 프레임워크 (Flutter 또는 React Native) ➡️ 단일 코드베이스로 글로벌 배포 속도 극대화.
* **Backend:** Node.js (NestJS) 또는 Kotlin (Spring Boot) 기반 마이크로서비스 아키텍처(MSA).
* **Data & Search:** PostgreSQL (관계형 데이터) + Redis (날씨 및 세션 캐싱) + OpenSearch (지리 정보/Geo-indexing 및 공간 검색).
* **AI Layer:** 경량 LLM API (다이어리 텍스트 요약) + 온디바이스 룰 엔진 (코디 추천).
* **Maps/Weather API Multi-Adapter:** 국내(Naver/Kakao), 글로벌(Google Maps, OpenWeather) API를 추상화 레이어로 통합하여 유저 위치에 따라 스위칭.

### ⚙️ 추천 및 자동화 구현 방식
1.  **코디 추천 알고리즘 (MVP 단계):** 가중치 스코어링 시스템(Rule-based Scoring) 적용.
    $$\text{Score} = (w_1 \times \text{Temperature}) + (w_2 \times \text{Rainfall}) + (w_3 \times \text{Activity Level})$$
    * *비 예보 시:* 방수 신발 및 아우터 스코어 가중치 업.
    * *도보 이동량 많을 시:* 캐주얼/스니커즈군 스코어 가중치 업.
2.  **장애 극복 정책 (Fallback Plan):**
    * 날씨/장소 API 장애 시 ➡️ 최근 3시간 내 로컬 캐시 데이터 혹은 해당 도시 계절 평균 데이터 서빙.
    * 번역 API 단절 시 ➡️ 앱 내 빌트인 정적 리소스 파일(`localizable.strings`)로 즉시 대체.

### 🔒 개인정보 보호 및 보안
* 위치정보 및 사진 접근은 국가별 법규(GDPR, 국내 개인정보보호법 등)를 준수하여 **명시적 선택 동의**로만 구동.
* 여행 종료 후 "1-Click 데이터 즉시 삭제" 기능 및 "오프라인 로컬 저장" 옵션 제공.

## 7. MVP(최소 기능 제품) vs 고도화 로드맵

| 구분 | MVP 범위 (1단계) | 고도화 범위 (2단계 이후) |
| :--- | :--- | :--- |
| **UX & 핵심기능** | - 다국어 온보딩 & 컨텍스트 홈<br>- 룰 기반 날씨 코디 제안<br>- 지도 기반 포토스폿 리스트<br>- 반자동 다이어리(EXIF 매핑) | - AI 기반 초개인화 스타일 학습<br>- 완전 자동 다이어리 문장 고도화<br>- 다인원(그룹) 실시간 공동 일정 관리<br>- 오프라인 여행 모드 지원 |
| **기술 & AI** | - 7개국어 정적 번역 및 단위 변환<br>- 룰 기반 스코어링 엔진<br>- 기본 카메라 2D 가이드라인 | - 이미지 분석 기반 의상 자동 태깅<br>- 완전한 AR 공간 촬영 가이드 오버레이<br>- 실시간 장소 혼잡도 딥러닝 예측 |
| **비즈니스** | - 패션 커머스 아웃링크 제휴<br>- 주요 거점 지역 관광 상품 연동 | - 프리미엄 구독 모델 (고급 템플릿, 백업)<br>- B2B 관광/유통 데이터 대시보드 판매 |

* **MVP 합격 기준 (Success Metric):** 유저가 최초 진입 후 **3분 이내**에 오늘의 '코디 선택'과 '첫 번째 행선지' 저장을 완료하고 이탈하지 않는 것.

## 8. 비즈니스 모델 (Monetization)

초기에는 서비스 신뢰도를 저해하는 무분별한 전면 광고를 배제하고, **콘텐츠 융합형 수익 모델**을 지향합니다.

1.  **네이티브 패션 커머스 제휴 (초기):** 추천 코디 카드 하단에 해당 스타일을 구매할 수 있는 글로벌 패션 플랫폼(예: 무신사 글로벌, W컨셉 등) 구매 링크 연동 (수수료 모델).
2.  **지역 관광 O2O 제휴 (중기):** 포토스폿 상세 페이지 내 인근 상권 쿠폰(카페, 편집숍) 발행 및 액티비티/입장권 예약 연동.
3.  **프리미엄 구독 서비스 (가치 성숙기):** 광고 제거, 다이어리 PDF 고해상도 인쇄 템플릿 제공, 무제한 클라우드 백업 공간 제공.

## 9. 론칭 단계별 로드맵 (Go-To-Market)

* **0단계 (사전 검증):** 랜딩 페이지 및 디자인 프로토타입 기반 인터뷰 ➡️ 가치 적합성(Problem-Solution Fit) 검증.
* **1단계 (MVP 론칭):** 국내 유저 타깃으로 핵심 루프(날씨-코디-스폿-기록) 안정성 테스트 및 리텐션(D1/D7) 확보.
* **2단계 (다국어 및 현지화 확장):** 방한 외국인 대상 마케팅 개시. 언어별 이탈률 모니터링 및 단위/지역 정보 데이터 고도화.
* **3단계 (수익화 다각화):** 글로벌 커머스 제휴 스케일업 및 구독 기능 오픈.

---
