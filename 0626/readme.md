# 2026년 제4회 문화체육관광 인공지능데이터 활용 공모전 (모집기간2026-04-27 ~ 2026-06-26)

## 📄 공모전 소개
데이터 활용 역량을 높이고 AI 기반 서비스 개발을 촉진함으로써, 우리 문화 생태계의 경쟁력을 강화하고 새로운 활력을 불어넣고자 합니다.  
기술과 문화의 융합을 통해 더 나은 미래를 설계할 여러분의 창의적인 아이디어와 열정적인 참여를 진심으로 기다립니다.

* 대한민국 국민 누구나
* 개인 또는 단체(5인 이내 / 기관, 기업 참가 가능)
* *※ 동일 작품 중복 응모 불가*
